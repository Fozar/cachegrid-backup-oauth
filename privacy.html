Cachegrid Backup

Privacy policy

Last updated: November 6, 2026

Who operates this app

Cachegrid Backup is a privately operated personal backup tool used by its owner. It is not a publicly hosted service.

Data and Google Drive access

The tool uses rclone and Restic to create and verify backups. Backup contents are encrypted on the client before they are stored. The Google Drive API is used to store, list, and read backup objects and verify recovery. The full Drive scope allows management of backups created by prior OAuth clients.

Google receives the storage data and API requests required for Google Drive operations. Access credentials are kept private. The tool does not sell data, show ads, or use third-party analytics.

Retention and deletion

The owner controls how long backups are retained; there is no automatic fixed-period deletion. The owner can delete stored backups through Google Drive.

Revoking access

You can revoke the app’s Google access from your Google Account’s third-party connections. Revoking access stops future operations that require authorization; it does not delete backups already stored in Drive. The owner can delete those backups through Drive.
