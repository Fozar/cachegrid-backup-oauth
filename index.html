Personal backup tool

Cachegrid Backup

Cachegrid Backup is a privately operated tool used by its owner to create and verify personal backups. It is not a publicly hosted service.

How it works

The tool uses rclone and Restic. Backups are encrypted on the client before storage. Google Drive API access is used to store, list, and read backup objects and to verify recovery. The full Drive scope allows the tool to manage backups created by earlier OAuth clients.

Access credentials are kept private. The tool does not sell data, show ads, or use third-party analytics.

Privacy

Google receives the storage data and API requests needed to operate Google Drive storage. The owner controls backup retention; backups are not automatically deleted after a fixed period.
